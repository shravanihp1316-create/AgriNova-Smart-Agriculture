# 🌱 AgriNova – Smart Agriculture Monitoring System

## 📌 Project Overview
AgriNova is an IoT-based smart agriculture project designed to help monitor agricultural conditions using sensor data and a dashboard. It aims to support farmers by presenting environmental information in an easy-to-understand format.

## ✨ Features
- **Monitoring Dashboard:** Displays temperature, humidity, soil moisture, and gas readings.
- **Sensor Data Integration:** Fetches the latest readings from ThingSpeak.
- **AI Farming Chatbot:** Provides farming-related responses through a chatbot interface.
- **Voice Interaction:** Includes speech input and text-to-speech functionality.
- **Multilingual Support:** Includes language detection for Kannada, Hindi, Tamil, Telugu, and English.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- ThingSpeak API
- Browser Speech Recognition and Speech Synthesis APIs
- Groq API for AI responses

## 🖥️ Dashboard
The dashboard contains four node panels for displaying sensor readings. The current code applies the same fetched readings to all four panels.
